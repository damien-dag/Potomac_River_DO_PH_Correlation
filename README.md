# Potomac_River_DO_PH_Correlation
Reproducible scatter plot of the direct biochemical synchronization between pH and Dissolved Oxygen levels across a 3-month period. Uses USGS water data from the Potomac River in WV, using the 'dataRetrieval' API package provided by the USGS.

*Reason for Plotting*

Plotting the co-dependent cycle of pH and DO (which serves as a primary indicator of river metabolism and gives a visualization of the metabolic health of the river) is useful if one wants to spot anomalous drops in either parameter. Tracking this drop could be a possible sign of an ecological threat such as an algal bloom or severe pollution.
